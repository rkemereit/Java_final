This is the Final for my Java 1 Class. Similar to the employee program I made, this is a Game store that works similarly.
The game store uses CRUD functions to edit a few aspects of the store. 
You can edit Employees, Customers, Transactions, as well as Games and look at the info of other game stores within the company.
The program takes a list from CSV files then edits them whenever data to one of the sections is changed.
